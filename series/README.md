# series/ — 연재 원본 MD

claude.ai 「나물려 연재」 프로젝트에 있던 MD 파일을 이 폴더로 옮겨 주세요.
매일 아침 자동 세션은 **이 폴더의 최신 내용**을 읽고 회차를 만듭니다.

| 파일 | 내용 |
|---|---|
| `characters.md` | 캐릭터 설정 (외형은 SVG 코드 또는 아주 구체적인 묘사로) |
| `style.md` | 그림체·컷 구성·말투·캡션/고정댓글 톤 |
| `plan.md` | 앞으로의 회차 로드맵 |
| `scripts/NNN.md` | 미리 써 둔 대본(선택). 없으면 자동 세션이 plan.md 기반으로 작성 |
| `feedback.md` | 인사이트 피드백 — 자동 세션이 매일 맨 위에 추가 |

파일 이름이 달라도 괜찮습니다. 이 폴더의 `.md`는 모두 읽습니다.
