# 나물려 툰 제작 코드 설명 (2026-11-25)

## 필요한 것
- Python 3 + Pillow(PIL)
- `rsvg-convert` (librsvg, SVG → PNG 변환)
- `ffmpeg` (릴스 MP4 인코딩)
- 글꼴: Noto Sans CJK KR (Black 굵기)
- 대본 DB md 2개(`나물려_대본DB_07-18.md`, `나물려_대본DB_19-30.md`)를 코드와 같은 폴더에 둔다. 경로는 `db.py`의 `FILES`, 출력 폴더는 `lib.py`의 `OUT`에서 바꾼다(기본값 /home/claude/toon).

## 실행
```
python3 ep17.py test   # 10번 카드 1장만 /tmp 에 미리보기
python3 ep17.py full   # 표지·카드 10장·다음 화 예고·릴스·릴스 커버를 out/ 에 생성
```

## 파일 역할
| 파일 | 역할 |
|---|---|
| **make.py** | 기본 엔진. 말풍선 4개 배치, 글씨 크기·줄바꿈(FIXED=48이면 48px 고정), SVG 생성. 나물려 원본 캐릭터 SVG(SCENE)도 여기에 있음 |
| **lib.py** | 공통 부품: 나물려 캐릭터(CHAR), 기본 자세(NMR_FRONT: 팔·휴대폰·손), 손(hand)·소매(cuff) 함수, 말풍선 배치(B2), 카드 SVG(_svg) |
| **lib2.py** | 워터마크(wm), PNG 변환(_png), 아이디·글꼴 상수. 11화까지 쓰던 표지·릴스 함수 |
| **lib3.py** | 9~10화용(시리즈 표시·노란 팔로우 띠). 지금은 안 씀(폐기 형식) |
| **lib4.py** | **현행 파이프라인(12화~)**: covers(표지·릴스 커버), cards(카드 10장 + 다음 화 예고), outro, reel(릴스: 첫 화면 질문+펀치 동시, 마지막 펀치 3.2초) |
| **db.py** | 대본 DB md에서 N화의 썸네일·대본 10세트·다음 화 제목을 읽음 |
| **ep2~ep17.py** | 화별 장면(배경·상대역 그림)과 실행 코드. 새 화는 비슷한 장면의 ep 파일을 복사해 배경만 바꿔 만든다(예: ep17 = ep15 팀장 + 사무실 배경) |
| cast.py | 등장인물 소개 카드 |
| hl.py | 하이라이트 커버(회사생활·사랑) |
| profile.py | 예전 프로필 사진 |
| covers.py, reel.py | 초기(2~4화) 표지·릴스 스크립트 |
| slow.py | 대본 DB 일정 일괄 수정용 1회성 스크립트 |
| make_v1_backup.py | make.py 초기 백업 |

## 상대역 그림 코드 위치
